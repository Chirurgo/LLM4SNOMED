# A Framework for Structuring Thai Medical Documents Using SNOMED CT and Large Language Models

This repository contains the code accompanying our study on structuring Thai clinical text using SNOMED CT and large language models (LLMs). The project aims to support automated extraction and normalization of clinical information from Thai medical documents through a modular pipeline combining named entity recognition, candidate retrieval, and concept linking.

## Overview

Clinical information in routine electronic medical records is often embedded in free text, which limits its reuse for analytics, interoperability, and secondary applications. This repository provides the implementation used in our study to evaluate an end-to-end framework for identifying medical entities in Thai clinical text and linking them to SNOMED CT concepts.
